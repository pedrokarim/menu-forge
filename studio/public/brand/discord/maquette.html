Images à téléverser

    

      Dossier studio/public/brand/discord/. La clé est le nom du

      Images générées par python scripts/discord_assets.py.
    

    

  


  
  

    
Comment faire

    

      
    
        
  1. 
          Ouvrir le portail développeur Discord,
          discord.com/developers/applications,
          puis New Application. La nommer exactement
          Menu Forge : c’est ce nom qui s’affiche après « Joue à ».
        
    2. 
        
  2. 
          Onglet General Information : copier
          l’Application ID (une suite de 17 à 20 chiffres).
        
    3. 
        
  3. 
          Dans le studio, Paramètres → Discord : coller cet
          identifiant dans Identifiant d’application et cocher
          Afficher mon activité.
        
    4. 
        
  4. 
          Portail, Rich Presence → Art Assets, puis
          Add Image(s) : téléverser les huit images de ce dossier.
          Pour chacune, vérifier que la clé proposée est exactement celle de la
          grille ci-dessus (logo, menu, asset,
          home, library, settings,
          workspace, about), puis
          Save Changes.
        
    5. 
        
  5. 
          Patienter quelques minutes : Discord met un peu de temps à diffuser les nouvelles
          images. En attendant, la carte montre un emplacement vide à la place de l’image.
        
    6. 
        
  6. 
          Côté client Discord, Paramètres utilisateur → Confidentialité de
          l’activité : Partager mon activité doit être activé.
        
    7.
